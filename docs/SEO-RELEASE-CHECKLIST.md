# Portfolio SEO and release checklist

## Page quality
- Keep each page focused on one clear user intent and avoid duplicating near-identical landing pages.
- Use a unique title, concise description, canonical URL, and one descriptive H1.
- Ensure internal links, navigation, and calls to action work on mobile and desktop.
- Keep visible claims consistent with structured data and metadata.

## Trust and accuracy
- Verify project descriptions, technologies, screenshots, and status before publishing.
- Obtain permission for client logos, testimonials, and private project details.
- Do not invent performance metrics, customer counts, certifications, or employment history.
- Keep contact details and service availability current.

## Technical release
- Run available automated checks before merging.
- Verify sitemap and robots directives after URL changes.
- Check image dimensions, alt text, keyboard navigation, and form validation.
- Review page performance and broken links after deployment.
- Record changed URLs and the release date for later Search Console inspection.
